# Hand Tracking & Computer Vision Projects

A collection of Python scripts utilizing OpenCV and MediaPipe for hand tracking, hardware interaction (Arduino/LEDs), 3D voxel manipulation, and TouchDesigner particle simulations.

## 📁 Included Projects

- **`hand_led_brightness.py`**: Controls LED brightness (PWM) via distance between fingers detected by webcam.
- **`hand_led_controller.py`**: Basic hand-tracking interface for sending serial control signals to Arduino LEDs.
- **`hand_tricking.py`**: Core hand landmark detection and tracking script.
- **`voxel_builder_controller.py`**: Gesture-controlled 3D voxel builder integration.
- **`touchdesigner_particle_sim.py`**: Sends hand tracking coordinates to TouchDesigner for real-time particle simulation.

## 🛠️ Tech Stack & Requirements

- **Python 3.x**
- **OpenCV** (`opencv-python`)
- **MediaPipe** (`mediapipe`)
- **PySerial** (`pyserial` - for Arduino integration)
